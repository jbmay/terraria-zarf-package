If steam updates the game client before that version releases for dedicated server, hold windows key and press r, this will launch run dialog box. Type the following and hit enter:
```
steam://open/console
```
This will open steam with console. In the console type the following:
```
download_depot 105600 105601 5751495116255795831
```
This will download a separate copy of terraria 1.4.5.6. This separate copy needs to be launched from file explorer, not from steam. Example file location where this gets saved so you can launch the older version:
```
C:\Program Files (x86)\Steam\steamapps\content\app_105600\depot_105601
```
You can pin the terraria executable to your toolbar if you want to be able to launch it without navigating to this folder.
